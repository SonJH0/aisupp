## 4. AI 활용 명세 

### 4-1. AI Agent 
- LLM이 2개 이상 도구를 **자동 선택**
- 입력 유형에 따라 analyze/search/chat 분기

| 도구 | 기능 | 예시 입력 |
|------|------|-----------|
| analyze | 이력서/스펙 분석 | "토익 900, 컴활 1급" |
| search | 직무 검색(RAG) | "백엔드 직무 추천" |
| chat | 일반 취업 상담 | "면접 준비 어떻게?" |

### 4-2. RAG 
- **질의마다** job.json 직무 데이터베이스 검색
- 사용자 스펙과 관련성 높은 직무를 검색해 근거 있는 추천 제공
- 검색 결과를 프롬프트에 주입

### 4-3. Prompt Engineering
- JSON 형식의 구조화된 답변 설계 (강점/약점/다음행동/근거)
- 취업 코치 페르소나 부여로 전문적인 상담 품질 확보
