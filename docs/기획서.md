# AI 취업 코치 (AI Career Coach) 기획서

> LLM과 RAG 기반의 개인 맞춤형 AI 취업 코칭 서비스

---

## 1. 프로젝트 개요

### 1-1. 한 줄 정의
**AI 취업 코치**는 취업 준비생의 보유 스펙(자격증·경력·기술)을 분석하여, 
AI Agent가 상황에 맞는 **직무 추천·역량 분석·취업 상담**을 자동으로 제공하는 
개인 맞춤형 풀스택 AI 서비스입니다.

### 1-2. 기획 의도
기존 취업 지원 서비스는 대부분 **"정보 제공"에 머물러** 있습니다.
채용 공고를 나열하거나, 자격증 정보를 보여줄 뿐 
**"그래서 내가 무엇을 해야 하는가"** 에 대한 답은 주지 못합니다.

본 프로젝트는 여기서 한 단계 나아가,
사용자의 입력을 **AI가 능동적으로 해석**하여 
"당신의 강점은 이것이고, 이 직무가 적합하며, 다음엔 이것을 준비하세요"라는 
**실행 가능한(actionable) 코칭**을 제공하는 것을 목표로 합니다.

### 1-3. 차별점
| 구분 | 기존 서비스 | AI 취업 코치 |
|------|-------------|--------------|
| 정보 제공 방식 | 단순 나열 (검색형) | AI 해석 + 맞춤 제안 (코칭형) |
| 사용자 입력 처리 | 키워드 필터링 | AI Agent 의도 분석 |
| 답변 근거 | 없음 또는 불명확 | RAG 기반 실데이터 근거 |
| 상호작용 | 단방향 조회 | 양방향 대화형 상담 |

## 2. 문제 정의 

### 2-1. 시장 배경
취업 시장은 매년 경쟁이 심화되고 있으며, 
직무는 세분화·전문화되는 반면 취업 준비생이 접하는 정보는 
**양은 많지만 개인화되지 않은** 상태입니다.

이로 인해 취업 준비생은 다음과 같은 **3단계 어려움**을 겪습니다.

[1단계: 자기 이해] → [2단계: 직무 탐색] → [3단계: 실행 계획]


### 2-2. 구체적 문제 정의

**① 자기 객관화의 어려움 (1단계)**
- 현상: 보유한 자격증·경력이 **어떤 강점으로 연결되는지** 스스로 판단 어려움
- 원인: 객관적으로 역량을 분석해주는 접근 가능한 도구의 부재
- 결과: 자신 없는 지원 → 낮은 합격률 → 자신감 하락의 악순환

**② 직무 탐색의 비효율 (2단계)**
- 현상: 수백 개 직무 중 **내게 맞는 직무**를 찾는 데 과도한 시간 소요
- 원인: 채용 플랫폼은 "검색"은 되지만 "추천"은 안 됨 (내 스펙 기반 X)
- 결과: 무분별한 지원 또는 탐색 포기

**③ 실행 계획 수립의 부재 (3단계)**
- 현상: "그래서 지금 뭘 해야 하지?"에 대한 답을 얻기 어려움
- 원인: 24시간 즉시 상담 가능한 창구 부족, 컨설팅은 고비용
- 결과: 방향성 없는 준비 → 시간·비용 낭비

### 2-3. 기존 대안의 한계

| 대안 | 장점 | 한계 |
|------|------|------|
| 취업 컨설팅 | 전문적·맞춤형 | **고비용**, 시간·장소 제약 |
| 채용 플랫폼 | 공고 다수 보유 | 단순 나열, **개인화 없음** |
| 커뮤니티/멘토링 | 실제 경험 공유 | 비정형 정보, **신뢰성 편차** |
| 일반 챗봇 | 즉시성 | **근거 없는 답변**(환각) 위험 |

### 2-4. 우리의 해결 방안

> 위 3단계 문제를 **하나의 서비스**에서 해결합니다.

[1단계 해결] 스펙 분석 기능 → 강점·약점·근거 제시 (LLM)

[2단계 해결] 직무 추천 기능 → 실데이터 기반 매칭 (RAG)

[3단계 해결] AI 상담 기능 → 다음 행동 제안 (LLM)

↑

AI Agent가 입력을 분석해 자동 분기

## 5. 기술 스택 및 선정 이유

### 5-1. Frontend

**선택: HTML / CSS / JavaScript + Vercel 배포**

| 항목 | 선정 이유 |
|------|-----------|
| Vercel | Git 연동만으로 **자동 CI/CD** 구축, 무료 SSL(HTTPS) 제공, 글로벌 CDN으로 빠른 응답 |


---

### 5-2. Backend

**선택: Python + FastAPI + Render 배포**

| 항목 | 선정 이유 |
|------|-----------|
| Python | AI/LLM 생태계(OpenAI SDK 등)와의 호환성이 가장 우수 |
| FastAPI | **비동기(async)** 지원으로 LLM API의 긴 응답 시간을 효율적으로 처리. **자동 Swagger 문서** 생성으로 API 테스트 용이 |
| Render | Python 서버 배포가 간편하고 무료 티어 제공. GitHub 연동 자동 배포 지원 |

> **대안 비교**: Flask도 가능했으나, FastAPI의 **비동기 처리**와
> **자동 문서화(Swagger UI)**가 LLM 기반 서비스에 더 적합하다고 판단함.
> (Django는 본 프로젝트 규모에 과한 무게감이라 제외)
