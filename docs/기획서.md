# AI 취업 코치 (AI Career Coach) 기획서

> LLM과 RAG 기반의 개인 맞춤형 AI 취업 코칭 서비스

---

## 1. 프로젝트 개요

**AI 취업 코치**는 취업 준비생의 스펙과 경력을 분석하여 
개인 맞춤형 직무 추천과 취업 상담을 제공하는 풀스택 AI 서비스입니다.

사용자가 보유 자격증·경력을 입력하면, AI Agent가 입력의 의도를 판단해 
**이력서 분석 / 직무 검색(RAG) / 취업 상담** 중 최적의 기능을 자동으로 수행합니다.

- **서비스 URL**: https://aisupp.vercel.app
- **GitHub**: https://github.com/SonJH/aisupp

---

## 2. 문제 정의 

### 2-1. 배경
취업 시장의 정보 비대칭이 심화되면서, 취업 준비생은 
"내가 무엇을 준비해야 하는지" 판단하기 어려운 상황에 놓여 있습니다.

### 2-2. 구체적 문제
| 문제 | 상세 내용 | 기존 대안의 한계 |
|------|-----------|------------------|
| 자기 객관화 어려움 | 본인의 강점·약점을 스스로 파악하기 힘듦 | 취업 컨설팅은 고비용 |
| 직무 탐색 비효율 | 수많은 직무 중 적합한 직무 찾기 어려움 | 채용 사이트는 단순 나열식 |
| 상담 접근성 부족 | 24시간 즉시 상담받을 창구가 없음 | 멘토링은 시간·장소 제약 |

### 2-3. 해결 방안
→ **AI Agent**가 사용자 입력을 분석해 상황에 맞는 기능을 자동 제공함으로써,
   누구나 **무료로, 즉시, 개인 맞춤형** 취업 코칭을 받을 수 있도록 함.

## 3. 타깃 사용자

### 3-1. 예시

**[예시 1] 취업 준비생**
- 상황: 자격증은 땄는데 어떤 직무에 지원할지 모름
- 니즈: "내 스펙에 맞는 직무를 추천받고 싶다"
- 사용 기능: 스펙 분석 → 직무 추천

**[예시 2] 직무 전환자)**
- 상황: 비전공자인데 IT 직무로 전환 고민
- 니즈: "뭘 공부해야 할지 로드맵이 필요하다"
- 사용 기능: AI 상담 → 학습 로드맵

### 3-2. 타깃 요약
- 취업 준비생 / 이직 희망자 / 직무 전환 재직자

## 4. 핵심 기능 

| 기능 | 설명 | 사용 기술 |
|------|------|-----------|
| 스펙 분석 | 강점/약점/다음 행동/근거 제시 | LLM + Prompt Engineering |
| 직무 추천 | 스펙 기반 적합 직무 검색 | RAG (job.json) |
| AI 상담 | 취업 관련 Q&A | LLM |
| Agent 자동 분기 | 입력 의도에 따라 도구 자동 선택 | AI Agent |

## 5. 기술 스택 및 선정 이유

### 5-1. Frontend

**선택: HTML / CSS / JavaScript + Vercel 배포**

| 항목 | 선정 이유 |
|------|-----------|
| Vercel | Git 연동만으로 **자동 CI/CD** 구축, 무료 SSL(HTTPS) 제공, 글로벌 CDN으로 빠른 응답 |


---

### 5-2. Backend

**선택: Python + FastAPI + Render 배포**

| 항목 | 선정 이유 |
|------|-----------|
| Python | AI/LLM 생태계(OpenAI SDK 등)와의 호환성이 가장 우수 |
| FastAPI | **비동기(async)** 지원으로 LLM API의 긴 응답 시간을 효율적으로 처리. **자동 Swagger 문서** 생성으로 API 테스트 용이 |
| Render | Python 서버 배포가 간편하고 무료 티어 제공. GitHub 연동 자동 배포 지원 |

> **대안 비교**: Flask도 가능했으나, FastAPI의 **비동기 처리**와
> **자동 문서화(Swagger UI)**가 LLM 기반 서비스에 더 적합하다고 판단함.
> (Django는 본 프로젝트 규모에 과한 무게감이라 제외)
